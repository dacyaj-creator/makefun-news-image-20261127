## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

The program copies the front page to `out/entry.png` (1024×1024, under 1 MiB). It runs offline on Node 22 with the standard library only, and two runs write identical bytes.
